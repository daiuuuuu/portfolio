Usage Rules / 使用规则

1. Z-Axis Layering: 深度通过堆叠平面容器实现，而非阴影。"surface"层直接位于"base"之上。

2. Zero Softness: 无模糊、无渐变、无环境光遮蔽。界面应如机械加工般锐利。

3. Accent Restraint: brand-accent (#8A84A3) 仅用于交互高亮、状态指示器或引导视线至单一技术细节。

4. Outline System: outline (#75777A) 用于主要边框；outline-variant (#C5C7C9) 用于暗色模式边框。

5. Error: error (#BA1A1A) / error-container (#FFDAD6) — 仅用于关键错误状态。
