## 五、设计系统

- **风格**：Radical Helvetica-Modernism（瑞士国际主义 + 构成主义 + 1980s 数字终端）
- **色彩**：灰阶六级（surface → outline）+ 信号紫 `#2E1065`（仅非文字）+ 暗色终端面板
- **字体**：Inter（正文）+ JetBrains Mono（技术标识）+ Geologica 900（英文大标题）
- **中文栈**：`PingFang SC, Microsoft YaHei, Noto Sans SC`
- **网格**：12 列 · 0px 圆角 · 1px 边线
- **禁止**：暖色背景 / 圆角卡片 / 玻璃拟态 / 渐变文字 / 柔和阴影 / border+shadow 同用 / 侧边描边>1px

## 六、架构规则

```
数据流：projects.ts（唯一数据源，60+ 字段/项目）→ ProjectDetail.tsx → 12 个区块组件
类型流：project.ts → projects.ts → 组件 props
样式流：globals.css @theme → Tailwind 类名 → 组件
空值处理：每个区块组件顶层数据守卫（if (!project.X?.length) return null）
新增项目：projects.ts 追加一个 Project 对象 → 路由和页面自动生成
```

## 七、动效系统（2026-08-03 最终状态）

### 已实现插件
`gsap.registerPlugin(ScrollTrigger, SplitText, ScrambleTextPlugin)`

### 核心模块

| 模块 | 文件 | 功能 |
|------|------|------|
| 文字揭示引擎 | `src/animations/scrollReveal.ts` | 进出对称：入场 clip-path wipe / 出场 opacity scrub。每行独立 ScrollTrigger。data-reveal / data-reveal="cover" / data-reveal="marquee" / data-reveal-group。 |
| 平滑滚轮 | `src/animations/smoothWheel.ts` | 速度模型：gsap.ticker + lerp。raw wheel 监听，目标速度追踪，停手自然衰减。内部滚动容器自动放行。 |
| 路由挂载 | `src/animations/useScrollReveals.ts` | 按路由挂载/清理（useGSAP revertOnUpdate）。resize + fonts.ready 自动 rebuild SplitText + ScrollTrigger。media-load 事件自动 refresh 触发位置。 |

### 参数约定
- 文字行：原地 clip-path wipe，1.4s expo.out，无位移
- opacity 旅程：底部 100%→92% 淡入 / 阅读区常亮 / 下边缘 15%→7% 淡出，三段时长按高度动态计算
- 滚动停止即冻结、回滚精确还原
- 组 stagger：步进 3% 视口（上限 12%）
- 只动 transform/opacity/clip-path

## 十二、开屏收尾 + 首页入场编排（2026-08-14 定稿）

> 开屏动画与首页 Hero 动效定稿。本节补充/修正第十一节。

### Boot 开屏（LoadingBoot.tsx）最终版
1. **揭幕方式 = 原地淡出**：不再 `yPercent:-100` 上滑。boot 内容（ASCII logo / 5 行日志 / 进度条）原地淡出（0.45s）后遮罩卸载，紫色对紫色无缝。`onComplete` 用**宏任务（setTimeout 20ms）**派发 `boot:reveal` 事件——不能在时间线 tick 内同步派发（会被 GSAP 吞掉导致 hero 入场不触发）。
2. **进度条与文字严格同步**：进度 = 行等权 `(已完成行 + 当前行进度)/总行数`；填条发生在字符出现的**同一瞬间**（无 10ms 滞后）；两者同刻到 100%。
3. **进度条纯白填充、无灰轨**：去掉 `░` 底轨，只留 `█` 增长；0% 时用不可见 NBSP 占行高，防布局跳变。
4. **barTotal 实测**：克隆进度条计算样式量 `█` 真实推进宽（~5px，含 letter-spacing），`floor(offsetWidth / charW)` 精确填满容器。原 `offsetWidth/4` 假设 4px/字符、少算 ~20% → 条会在 ~80% 进度时就视觉满格。
5. **`charByChar` 抽到共享模块** `src/animations/charReveal.ts`（含 `GLITCH_CHARS`），开屏与书签文字共用同一函数，保证逐字效果完全一致。
6. **滚动锁定**：boot 期间 `RootLayout` 设 `documentElement.overflow:hidden` 锁死页面滚动（滚轮/键盘/触摸全挡），`smoothWheel` 延迟到 `booting→false` 后才初始化；boot 结束瞬间解锁 + `scrollTo(0)` 回顶 + 启动 smoothWheel——否则 boot 期间滚动会让揭幕呈现滚过的画面。
7. **滚轮快进**：开屏时滚轮事件推进 `tl.progress + 0.15`，没耐心的访客滚滚轮即可快速播完动画（滚动仍被锁，滚轮只驱动快进）。
8. **内容加载门控**：`onComplete` 先等雕塑图加载完（`complete && naturalWidth`，2.5s 兜底）才派发 `boot:reveal`/卸载——快进也不会露出未加载的雕塑。

### 首页 Hero 入场编排（HeroSection.tsx）
- 由 `boot:reveal` 事件触发，**首次加载播一次**；SPA 回首页保持静态（`window.__bootRevealed` 标记）。`prefers-reduced-motion` 全跳过。
- **入场顺序**：
  1. ① **背景**：色块（从左上沿 45° 旋转轴滑入，纯 translateX）+ 滚动条 ×10（从屏外沿各自漂移方向滑入）；
  2. ② **书签 + 印章**（同起点）：书签从右沿 2° 斜度滑入、印章从上方落下（无淡入）；
  3. ③ **雕塑**：书签动画中点开始，从左滑入（无 opacity 淡入）。
- **书签头**：左端 SVG 三角形（深紫填充 + 上下白细边 + 尖端圆弧），`right-full` 挂在书签条左端，随书签滑动。
- **书签文字**：滑动入场时两段文字**都隐藏**（opacity 0），书签到位后「DAIU — DESIGN PRODUCTION」与「PORTFOLIO 2026」**同时**逐字揭示（`charByChar`，与开屏同款）；之后主文字每 4s 周期重播 ScrambleText 乱码。
- **雕塑**：
  - **性能**：4k（4320×5460，23.6MP）→ 2k（2160×2730）。原 opacity 淡入每帧降采样 23.6MP → 帧耗 24ms；改为 2k + 纯 transform（去 opacity 淡入）→ ~20ms，不再卡。
  - **紫色**：烘焙进素材 `首屏-天使雕塑-紫色.webp`（lossless webp）——暗部精确 = 背景品牌紫 `#2E1065`（与背景融合），亮部浅紫 `#B6AAEE`，保留抠图透明通道（滚动条透出）。**不能用 `mix-blend-color` 覆盖层**：会填充透明区成实心矩形挡住滚动条。纯 CSS filter（grayscale+sepia+hue-rotate）又无法让暗部精确等于背景紫，故烘焙。
- **font token**：`--font-mono` / `--font-mono-technical` 从 Inter 改为 `JetBrains Mono`（见第十一节第 4 条）。
