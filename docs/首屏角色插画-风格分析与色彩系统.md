## 〇、核心定位

这不是"抄角色画风"——我们不需要画角色。要提取的是这四张图**共享的色彩空间、光影逻辑、材质处理方式**，然后把它们翻译成作品集背景可以使用的设计语言。

四张图的共通语言可以概括为：

> **深空暗底 + 高饱和霓虹信号 + 斜向动线 + 冷峻工业材质**

## 一、色彩系统

### 1.1 基底（暗区）

| 色值 | 名称 | 用途 |
|------|------|------|
| `#0B0E14` | Void Black | 最深背景区，纯黑偏移 5% 蓝 |
| `#111827` | Deep Navy | 主背景底，午夜蓝基调 |
| `#1A1F2E` | Dark Slate | 次级暗区，有轻微暖意 |
| `#232838` | Elevated Dark | 抬升面板/卡片底 |

**关键原则**：底色绝不用 `#000000`。用带蓝色/紫色偏移的极深色，保留"纵深感"。

### 1.2 霓虹信号色（Accent / Neon）

| 色值 | 名称 | 用途 | 出现频率 |
|------|------|------|:--:|
| `#FF6B2B` | Burnt Orange | **主信号色**——高光、描边、能量核心 | ★★★★★ |
| `#FF8C42` | Amber Glow | 柔化版橙色，大面积发光、渐变过渡 | ★★★★ |
| `#FFD93D` | Electric Yellow | CTA 级强调、最亮高光点 | ★★★ |
| `#00D4C8` | Cyan Signal | 第二信号色——数据界面、科技元素 | ★★★ |
| `#0AE0D4` | Teal Glow | Cyan 的暖化变体 | ★★ |
| `#7B2FBE` | Deep Violet | 氛围色——背景光晕、角色阴影补光 | ★★★★ |
| `#C084FC` | Soft Purple | 紫色高光——稀有度/能量层级标识 | ★★★ |
| `#FF2D95` | Neon Magenta | 极少使用——仅在最高能量点出现 | ★ |

### 1.3 灰阶（中性过渡）

| 色值 | 用途 |
|------|------|
| `#2A2D35` | UI 面板暗区 |
| `#3D4148` | 分割线、边框 |
| `#6B7280` | 次级文字 |
| `#9CA3AF` | 正文灰 |
| `#D1D5DB` | 高亮文字 |

### 1.4 色彩比例（一张典型画面的分布）

```
███  基底暗色 (Deep Navy / Void Black)   55-65%
███  紫/蓝氛围光晕                         15-20%
███  橙色/黄色信号                         10-15%
███  青/蓝灰过渡                            5-10%
```

**核心公式**：暗色占 60%+ → 紫/蓝光晕填中层 → 橙/黄/青在 10-15% 面积上爆发。**大面积暗、小面积亮、信号色极度克制**。

## 二、光影逻辑

### 2.1 三点照明模型

```
         Rim Light (Cyan/Teal)
              ↖
              ╲
               ╲  角色轮廓
                ╲
  Key Light ────→ ☻ ←──── Ambient (Purple/Violet)
  (Orange/Warm)   主体      (从下方/后方补光)
```

- **主光（Key）**：暖橙色，从右侧或右上方打入，强度最高
- **轮廓光（Rim）**：冷青色，从左侧/后方勾勒角色边缘
- **环境光（Ambient）**：紫色，从下方或后方填补阴影，防止死黑

### 2.2 光晕/Glow 效果

所有信号色都带 **bloom/辉光扩散**——不是生硬的色块，而是边缘柔化、向外衰减的光晕：

- 橙色元素：`box-shadow: 0 0 40px rgba(255,107,43,0.3), 0 0 100px rgba(255,107,43,0.1)`
- 青色元素：`box-shadow: 0 0 30px rgba(0,212,200,0.25)`
- 紫色氛围：大面积径向渐变，中心 opacity 15-20%，边缘归零

### 2.3 高光 vs 阴影对比

| 区域 | 亮度 | 说明 |
|------|:--:|------|
| 信号色发光区 | 100% | 画面最亮点，吸引第一眼 |
| 角色受光面 | 70-85% | 主光照射的皮肤/服装 |
| 暗面/阴影 | 5-15% | 几乎融入背景，轮廓光为边界 |
| 背景 | 0-5% | Void Black 区域 |

**对比度极高**——亮部过曝、暗部吞噬。不是柔和过渡，是**硬切**。

## 三、材质与纹理

### 3.1 观察到的材质类型

| 材质 | 在哪出现 | 视觉特征 |
|------|---------|---------|
| **金属拉丝** | 武器、机械臂、面板边框 | 细密平行线，方向一致，略有各向异性高光 |
| **磨砂暗面** | 服装深色区、背景大面 | 极细颗粒感，没有镜面反光 |
| **发光体** | 能量核心、UI 指示器 | 中心过曝纯白 → 色彩光晕 → 衰减到透明 |
| **半透玻璃/HUD** | 眼镜、数据面板 | 45° 斜向渐变，一侧实一侧虚 |
| **工业橡胶/哑光** | 战术装备、手套、绑带 | 完全无高光，吸光材质 |

### 3.2 对我们有用的

**磨砂暗面**：给首屏纯黑/深蓝背景加一层 `feTurbulence` 噪点（已有 letterpress 滤镜，可复用思路）

**发光体**：Stats 数字、CTA 按钮、关键标签可以用多层 `box-shadow` 模拟 bloom

**半透 HUD**：Profile 区可以叠加一个斜向透明带（45° 对角线光条）

## 四、构图规律

### 4.1 视觉动线

四张图共享同一条对角线逻辑：

```
 左上暗区 ────────────╮
                      ╲
                        ╲  45° 斜向动线
                          ╲
                            ╲
                              ╲─────── 右下亮区（角色/动作/能量）
```

- **左上**：暗、静、密（密集纹理/数据/文字）
- **右下**：亮、动、疏（角色主体/动作/发光元素）
- 沿着 45° 线从"信息密集"过渡到"视觉焦点"

### 4.2 非对称平衡

| 象限 | 内容 | 密度 |
|------|------|:--:|
| 左上 | 暗纹/文字碎片/数据 | 高 |
| 右上 | 过渡区/半透明带 | 中 |
| 左下 | 暗色留白/环境光 | 低 |
| 右下 | 主视觉/角色/能量 | 极高（亮度） |

### 4.3 对我们首屏的应用

把上述四象限映射到作品集 Hero：

```
┌──────────────────────────────────┐
│ [LOGO/MONO LABEL]    [STATUS]    │  ← 左上角小字
│                                  │
│   AIGC                            │  ← 巨型暗纹（左上→右下扩散）
│      _WORK                        │
│                                  │
│              ╲  45°光带斜切       │  ← 半透明斜向渐变带
│                ╲                 │
│                                  │
│                    / KONG DEYU   │  ← 右下角主标识
│                    SYS.VER ...   │
└──────────────────────────────────┘
```

### 5.2 不引入

| 元素 | 原因 |
|------|------|
| 角色插画本身 | 不是画师，也偏离"设计生产系统"叙事 |

| 游戏 UI 元素（血条/技能栏） | 不相关 |

## 六、对"页面加 2"（Hero 背景图）的具体建议

### 图片选择

四张图中，推荐 **`b32a0d5947659c3560de8823e9b1f6d4.jpg`（图 4）** 作为首屏背景。理由：
- 构图最"安静"——角色坐姿，动线清晰，不抢夺前景文字
- 色彩最丰富——橙/紫/青/深蓝四色俱全，可提取的 token 最多
- 左侧/上方有大量暗区——天然给文字留出可读空间
- 机械/工业元素——与"设计生产系统"的工程化叙事最接近

### 用法

不是直接把 1080×2374 竖图铺满 16:9 屏幕。建议：

1. **裁剪/遮罩**：截取画面的上半部分（角色头部到肩部，约占原图 40%），放在 Hero 右侧
2. **左侧暗区覆盖**：原图左侧用 `linear-gradient(to right, #0B0E14 0%, transparent 60%)` 渐变覆盖，确保左上角的文字清晰可读
3. **上方渐变过渡**：顶部加 `linear-gradient(to bottom, #0B0E14 0%, transparent 30%)`，让导航栏区域完全干净
4. **整体透明度**：图片 opacity 控制在 60-75%，作为"氛围底"而非"前景主体"
5. **信号色提取**：从图中取色做 accent——橙色 `#FF6B2B` 给 Stats 数字，青色 `#00D4C8` 给技术标签
