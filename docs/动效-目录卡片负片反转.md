# 目录卡片海报动效方案 · 负片反转

> 状态：已实现 （GSAP 3.15 · ProjectIndexItem · hover clip-path circle）
> 日期：2026-07-17

## 触发

鼠标 hover 目录卡片（`ProjectIndexItem`）右侧海报图片

## 动效描述

以海报图片为中心，发生"负片反转"：

1. 黑色圆形从海报中心向外扩散，覆盖整张卡片
2. 海报等比例放大（scale 1.35），保持在扩散中心
3. 原有黑色文字淡出，白色项目描述文字同时淡入
4. 卡片从白底黑字档案模式翻转为黑底白字沉浸模式

## 时间线

```
  0ms   · 海报 scale(1) 静止
200ms   · clip-path: circle(0→100%) 从海报中心扩散（400ms ease-out）
300ms   · 黑字 opacity 1→0 + 白字 opacity 0→1（300ms 交叉淡入淡出）
500ms   · 海报 scale(1→1.35)（400ms，带 overshoot 弹性回弹）
900ms   · 完成 · 稳定态
```

## 技术要点

| 点 | 说明 |
|------|------|
| **文字切换** | 双层叠放：黑字层 opacity→0，白字层 opacity→1，不能直接 tween color |
| **扩散形状** | `clip-path: circle()` 从图片中心展开，比方形扩散更自然 |
| **覆盖范围** | 仅当前 `<article>` 内，用已有的 `overflow-hidden` 约束 |
| **白字内容** | 仅保留一段核心描述（~60字），信息量精简，保持视觉冲击力 |
| **移动端** | 无 hover，保持默认态，不需要降级处理 |
| **实现** | GSAP timeline + clipPath + scale + opacity |
