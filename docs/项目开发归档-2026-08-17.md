## 四、Bug 根治（三个顽固问题）

### 1. Hero 开屏卡紫屏（回主页卡最后一帧）→ 已归档
- **根因**：`window.__bootRevealed` 只在 HeroSection 的 `playOnce` 设置。首屏落在项目详情页时 hero 从未挂载 → 标志永远 undefined → 回主页走 `else` 分支等一个永不重发的 `boot:reveal` → 最长 3.5s 纯紫屏
- **修复（两层）**：
  - LoadingBoot 揭幕时**独立设置** `__bootRevealed = true`（不依赖 hero 是否挂载）
  - HeroSection 入场加 **4s 强制完成保险丝**（时间线被杀则 gsap.set 全部最终态）
- **验证**：Playwright 首屏落项目页→HOME 时序，t<1500ms 进场（修复前 t≈4353ms）
- 详见 `docs/Bug-开屏动画卡紫色帧-hero入场竞态.md`

### 2. XCU 文字不显示（多次复发，本次根治）
- **第一次复发**：reveal 擦除 tween 被 `ScrollTrigger.refresh()`（图片懒加载触发）重建触发器时 kill → 行冻结在随机 clip-path 进度 → 加 **`selfHealWipes`**（refresh 后阅读区内强制揭示）
- **第二次复发（本次）**：`addExitJourney`（表格行整块淡出）用**预计算触发带** + scrub，被 XCU **钉住横向滚动区**污染几何 → strategy/process 整卡 `opacity: 0`
  - 证据：XCU 幕布路径 8 卡 opacity 0；duanfu（无钉住）正常；resize 重建救不回 → 系统性几何错误
- **根治**：`addExitJourney` 改为**实时读取 `getBoundingClientRect()`** 算 opacity（实时几何永远真实，屏上行不可能卡隐），同时自愈扩展到 opacity + exit targets
- **验证**：XCU 直接加载/幕布路径阅读区整卡隐藏峰值均 **0**；出场淡出仍生效（卡底近顶时 opacity 正常变小）

### 3. NEXT 双衬线
