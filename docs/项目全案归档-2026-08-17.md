## 二、本轮完整工作历程

### 阶段 1 · 全面审阅（起点）
- 通读全部文档（README/cloud/CLAUDE/PRODUCT/组件库/参考站）、源码、动效系统、数据模型。
- 输出全面点评：亮点（文档纪律、动效工程、Bug 根治文化）+ 待改进（bundle 体积、依赖分类、移动端、SEO、repo 卫生）。

### 阶段 2 · 端适配 v1→v2（社区调研 + 基础设施）
- **v1（响应式重排）**：用户实机看后否定，明确"不要重排成移动端单列"。
- **社区调研**（container queries / dvh / safe-area / 微信 X5 / 超宽屏）→ 补进 v2：
  - `viewport-fit=cover`（safe-area 前提）、`100dvh` 兜底、`-webkit-text-size-adjust`、`overscroll-behavior`、超宽屏不全局封顶。
  - 新增 `.h-viewport / .min-h-viewport-nav / .pt-safe/.pb-safe / .scroll-container` 工具类。
- **移动导航**：<lg 原本无导航，新增汉堡按钮 + 全屏抽屉（HOME/PROFILE/WORKS/CONTACT 或项目页 HOME/OVERVIEW/Q&A/NEXT + ↑TOP/GITHUB），滚动锁定、路由自动关。

### 阶段 3 · 端适配 v3（桌面等比混合——用户拍板）
- **纯缩放方案被浏览器实测否决**：`html{zoom}` 会把 vw 单位二次缩小 5 倍；`width=1920` 视口被 Chrome 忽略。
- **用户选「结构保列 + 正文整行」**：结构区块（统计/技能/技术栈/质量核对/组件样例）保持桌面多列；大段正文整行保证中文可读。
- 落地：Profile/ProjectIndex/ProjectHero/各详情区块/Showcase 全部按此调整。
- **移动端关闭吸附**：`ProjectIndexSection` 的 glide 吸附包进 `gsap.matchMedia('(min-width:768px)')`。
- **英雄区标题溢出**：英文大标题 `whitespace-nowrap` 在 1024-1600px 溢进封面 → JS 自适应缩放 + 容器 overflow-hidden。
- **首屏雕塑**：移动端左下贴底、压书签条（用户意图）。

### 阶段 4 · 第 6 项目（portfolio-site）内容刷新
- 数据全面刷新：53 源文件 / 5 动效模块 / 19 区块 / 0 横溢 320-2560 / <2s；补 GSAP 动效文字描述。
- 方案对比 / 流程架构：第 6 项目去表格外框（`project.slug === 'portfolio-site'` 条件），间距分隔。

### 阶段 5 · 组件库
- 盘点：43 组件里展示区缺 3 个（41 暗色页脚 / 42 CRT 扫描线 / 43 暗色网格）→ 补齐。
- **自包含**：参考库集合页用 iframe 相对路径嵌 43 组件，复制进 public 后路径失效（"显示不出来"根因）→ 复制 `组件库/` 目录恢复。
- 组件库页用 Tailwind CDN，国内被墙 → 用 Playwright 预编译 Tailwind 内联，43 个文件全部自包含（`scripts/selfcontain-lib.cjs`）。
- 展示区加「查看完整组件库 ↗」跳转按钮（镂空 → 悬停紫色）。

### 阶段 6 · 作品集 PDF / 长图 / 简历
- **极简版**（15 页 1920×1080 横版）：封面(网站首屏截图) / 简介 / 6 项目×2 页 / 结尾，设计语言与网站一致。
- **PDF 尺寸坑**：webp 被 Chromium 重编码膨胀（40MB）→ 改 JPEG 直嵌（2MB）。
- **长图**：极简版各页竖拼 + 网站完整版长图（1920×82376px，7 个路由整页截图拼接）。
- **简历**：A4 瑞士风（与网站同视觉），含证件照；文案突出 AI/成本/效率。
- 交付文件汇总到 `作品集交付/`（大文件不入仓库，gitignore）。

### 阶段 7 · XCU 设计规范提取展示
- 新增「AI 设计规范提取」区块：AI 管线（VIS→AI 逐页→TOKEN）+ 真实 logo 三变体（全彩/反白/单色）+ 安全空间/最小尺寸/误用示例 + 色彩色带（含 CMYK）+ 字体层级 + 网格 + 应用系统。
- 内容取自 `2_xcu/科技园形象/许昌大学科技园_设计风格提取.md`（253 行 AI 提取规范）。
- 用户反馈迭代：删反白/单色、删辅助图形、色彩改无边色带。
- **修复横向滚动 pin**：添加设计规范后 `trigger: section` 把整块 pin 住、滚动条位置错乱盖住 logo → 改 `trigger: track`。

### 阶段 8 · 性能优化（国内加载慢）
- **自托管字体**：下载 Inter/Geologica/JetBrains Mono woff2 → `public/fonts/`，删 Google Fonts CDN（渲染阻塞，国内被墙导致卡白屏）；`fonts.ready` 加 3s 超时兜底。
- **压缩大图**：15 张 3-5MB 主海报 → 1400px webp（33MB→2MB，16×）；删除未引用大 PNG（public/images 37MB→7MB）。
- **实测验证**：阻断 Google Fonts 下字体本地加载、0 墙外请求、全站 0 裂图。

### 阶段 9 · GitHub 同步
- 多次提交推送（端适配、第6项目、组件库、XCU 设计规范、性能优化），每次 GitHub Actions 自动部署并验证线上。

## 三、关键决策与踩坑细节

| 主题 | 决策 / 坑 | 说明 |
|---|---|---|
| 纯缩放不可行 | `html{zoom}` + `width=1920` 均被否决 | vw 二次缩小 / 视口被忽略，浏览器实测 |
| 移动端取舍 | 结构保列 + 正文整行 | 375px 下多列比例与中文可读不可兼得 |
| 吸附 | 移动端关闭，桌面保留 | `gsap.matchMedia('(min-width:768px)')` |
| 组件库 iframe | 相对路径复制后失效 | 复制 `组件库/` 目录恢复相对路径 |
| 组件库 CDN | Tailwind CDN 国内被墙 | Playwright 预编译内联，43 文件自包含 |
| PDF 体积 | webp→jpeg | Chromium 重编码 webp 膨胀；JPEG 直嵌 2MB |
| 标题溢出 | 1024-1600px nowrap 溢出 | JS 自适应 + overflow-hidden |
| 横向滚动 pin | 加内容后位置错乱 | trigger 从 section 改 track |
| 字体 | Google Fonts 渲染阻塞 | 自托管 woff2 本地加载 |
| 图片 | 3-5MB PNG 加载慢 | 1400px webp（16× 缩小） |
| 交付大文件 | 不入仓库 | gitignore：portfolio-pdf/site-longimg/作品集交付/简历 等 |
